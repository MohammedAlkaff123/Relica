# Instructions for AI tools working in this repo

## Leave no trace of yourself in the work

- Commits are authored by the human team member alone. Never add "Co-Authored-By", "Generated with" or any similar attribution line to a commit message or pull request.
- Never commit chat logs or prompt dumps.
- Code comments are welcome. Write them to explain the code to the team.
- Before any push, check `git log` for attribution lines.

Tool config files such as `.claude/`, `CLAUDE.md` and this file may stay in the repo.

The one place AI is named is `AI_USE.md`. It is the team's own disclosure log, and the NASA Space Apps rules require AI use to be disclosed. When you make or change something, remind the person to add a line there.

## Project

Read `docs/team/PLAN.md`, `docs/team/STORY.md` and `docs/team/TASKS.md` before changing anything. Stay inside the folders owned by the person you are working for (see the table at the top of `docs/team/TASKS.md`). Code layout and contracts: `docs/DEVELOPERS.md`.
